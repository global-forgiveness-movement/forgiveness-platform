Accessibility

Forgiveness is for everyone, so this site has to be too. We build to WCAG 2.1 AA — including keyboard navigation, visible focus, sufficient contrast, reduced-motion support, and captions on every video we publish. Transcripts ship with the video series.

If anything here is hard to use with your eyes, ears, hands, or assistive technology, that’s a defect and we want to know. Please tell us via the contact page and we will fix it.

A formal conformance report will be published alongside the site’s launch.
